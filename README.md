## ⚙️ О проекте

**DiscordFix** — готовая программная сборка для Windows, предназначенная для настройки сетевого подключения и работы с различными конфигурациями.

В проекте собраны:

* готовые конфигурации подключения;
* несколько вариантов сетевых параметров;
* инструменты для проверки работоспособности;
* настройки GameFilter;
* диагностика распространённых проблем;
* автоматический запуск выбранной конфигурации;
* дополнительные списки доменов и IP-адресов.

Набор параметров может отличаться по эффективности в зависимости от версии Windows, провайдера и текущих условий сети.

## 📦 Установка

1. Откройте раздел **Releases** и скачайте актуальный архив проекта.
2. В свойствах архива при необходимости нажмите **«Разблокировать»**.
3. Распакуйте архив в отдельную папку без кириллицы и нестандартных символов в пути.
4. Запустите `DiscordFix.exe`.
5. Выберите подходящую конфигурацию и проверьте подключение.

> [!TIP]
> Если выбранный вариант работает нестабильно, попробуйте другую доступную конфигурацию. Результат может зависеть от сетевого окружения.

## ⚙️ Возможности

### Конфигурации

Проект содержит несколько подготовленных вариантов настроек. Они предназначены для разных условий подключения и могут отличаться используемыми параметрами.

### GameFilter

Для GameFilter можно отдельно задавать диапазоны TCP-портов.

Например:

```text
1024-1934,1936-65535
```

Такой вариант позволяет исключить отдельный диапазон портов из обработки.

### Диагностика

В сборке предусмотрены инструменты для проверки основных компонентов и поиска распространённых проблем с подключением.

Диагностика может помочь определить:

* состояние используемой конфигурации;
* проблемы с сетевыми параметрами;
* состояние необходимых компонентов;
* доступность отдельных ресурсов;
* необходимость очистки кэша Discord.

## 📁 Структура проекта

## 🔄 Обновление

При выходе новой версии рекомендуется:

1. скачать свежий архив из **Releases**;
2. распаковать его в новую папку;
3. перенести только собственные изменения и дополнительные настройки;
4. повторно проверить выбранную конфигурацию.

## ❓ Частые проблемы

### Discord не подключается

Попробуйте:

* закрыть и заново запустить Discord;
* проверить другую конфигурацию;
* выполнить диагностику;
* очистить кэш Discord;
* перезапустить компьютер после изменения системных параметров.

### Конфигурация перестала работать

Сетевые условия могут изменяться, поэтому ранее рабочий вариант со временем может потребовать замены.

В таком случае проверьте другие доступные конфигурации и установите последнюю версию проекта.

### Не работает отдельное приложение или игра

Разные программы используют различные протоколы, серверы и диапазоны портов. Поэтому настройки, подходящие для Discord, не обязательно будут оптимальны для другого приложения.

Для отдельных случаев можно использовать **GameFilter** и дополнительные списки адресов.

## 📝 Пользовательские списки

При необходимости дополнительные адреса можно добавлять в пользовательские файлы конфигурации.

Это позволяет сохранять собственные изменения отдельно от основных файлов проекта и переносить их между обновлениями.

Рекомендуется использовать пользовательские списки вместо изменения базовых конфигураций.
